# 🎓 Online Student Management System (OSMS) - Bethel University

A comprehensive, role-based Online Student Management System built using PHP and MySQL. This system streamlines university operations by providing dedicated portals for Administrators, Teachers, Academic Officers, and Students.

## ✨ Features by User Roles

👑 **Admin Portal:**
* Register and manage Academic Officers, Teachers, and Students.
* Monitor overall student results and system activities.
* Profile management and account activation/deactivation.

👨‍🏫 **Teacher Portal:**
* Manage subjects across different grades (Grade 6 to 11, etc.).
* Upload and manage lesson notes for students.
* Create assignments, set deadlines, and view submitted answers.

🏢 **Academic Officer Portal:**
* Handle new student registrations.
* Search and view detailed student results and assignment marks.

🎓 **Student Portal:**
* View enrolled subjects and download lesson notes.
* Access assignments and track completion.
* Manage profile details and handle trial period/system payments.

## 🛠️ Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
* **Backend:** PHP (Core)
* **Database:** MySQL
* **Environment:** XAMPP / WAMP
